JavaScript, from your first variable to system architecture.

Fifty-five days: a 30-day core course, a 10-day interview bootcamp and 15 days of platform, backend and engineering depth, in eleven weekly pages and 119 topics. Every topic has an Explain like I’m 5 tab and a Technical tab, a diagram, runnable examples, edge cases, interview questions with model answers, and a two-minute “teach it” script.

How to use this course

  • Read the 5-year-old tab first. If you can say the analogy out loud, you own the mental model. Then read the Technical tab for the exact behavior.
  • Press ▶ Run on every example after predicting the output. The code runs live in your browser.
  • Do the tricky-output quiz at the end of each day before moving on. These are the questions interviewers actually ask.
  • Tick the day complete only when you can teach it using the “Teach it in 2 minutes” box. Progress is saved in this browser.
  • Version note: language status is as of November 2026 (ES2026 published; Temporal and using expected in ES2027; decorators still a proposal). Browser support figures change, so check MDN before relying on a specific version number.
  • Weeks 7–8 are the interview bootcamp: coding rounds (polyfills, async, algorithms, UI) and architecture rounds (system design, real-time, performance, behavioral). Every solution there is runnable and ships with self-checks that print pass/FAIL.
  • Weeks 9–11 fill the remaining gaps (OOP and SOLID, functional programming, algorithms, binary data and Intl, debugging, routing, forms, accessibility, Web Components, authentication, Node APIs, databases, caching, Git/CI, deployment, WebAssembly, ASTs). React and TypeScript are intentionally not covered.
  • A revision sheet closes every week. Use Print (Ctrl/Cmd+P) to get a clean copy with both explanation styles expanded.
